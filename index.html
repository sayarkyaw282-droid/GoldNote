⚙ Settings & Backup

🔐 Privacy Lock

PIN ဖြင့် app ကို lock/unlock လုပ်ပါ။ ဤ prototype တွင် PIN lock သည် app မျက်နှာပြင်ကိုသာ ကာကွယ်ပြီး ဒေတာကို အပြည့်အဝ encrypt မလုပ်ပါ။

📦 Backup / Restore

JSON ဖိုင်အဖြစ် export လုပ်ပြီး လုံခြုံသောနေရာတွင် သိမ်းထားပါ။ Restore လုပ်လျှင် လက်ရှိမှတ်စုများနှင့် ပေါင်းထည့်မည်။ Cloud sync ကို မချိတ်ဆက်ရသေးပါ။

📁 Categories

အခြေခံအမျိုးအစားများ — ကိုယ်ပိုင်၊ လုပ်ငန်း၊ လေ့လာမှု၊ အရေးကြီး။

🎙 Voice Notes

အသံဖမ်းခြင်းကို IndexedDB ဖြင့် ဒီဖုန်းထဲတွင် Offline သိမ်းနိုင်သည်။ အသံမှစာသားပြောင်းခြင်းကတော့ browser/device ပံ့ပိုးမှုအပေါ်မူတည်ပြီး Offline အလုပ်လုပ်မည်ဟု အာမမခံနိုင်ပါ။ Browser data မဖျက်ပါနှင့်။ Audio ဖိုင်များကို JSON backup ထဲ မထည့်သေးပါ။
